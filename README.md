# DEAD BREATH

Survival horror psicológico em primeira pessoa. Um homem comum, sedentário e asmático, fica preso na própria casa durante uma invasão. Ele não pode lutar, e o próprio corpo ameaça denunciá-lo.

| | |
|---|---|
| Gênero | Survival Horror · Psychological Horror · Stealth |
| Plataforma inicial | PC Windows |
| Engine | Godot 4.7.2 + GDScript tipado + GodotPhysics3D (ADR-001 aprovada) |
| Fase atual | **FASE 1 — Foundation** (em andamento) |
| Código de jogo | Em construção (`game/`) |
